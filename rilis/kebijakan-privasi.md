# Kebijakan Privasi — Dunia Kita

**Berlaku sejak:** 24 November 2026
**Versi aplikasi:** 1.0
**Pengembang:** Uhlabs (https://uhlabs.id)

## Ringkasan

Dunia Kita **tidak mengumpulkan, menyimpan, atau membagikan data
pribadi apa pun**. Game ini dimainkan sepenuhnya di perangkat Anda,
tanpa akun, tanpa iklan, dan tanpa pembelian dalam aplikasi.

## Data yang kami kumpulkan

Tidak ada. Secara rinci:

- **Data pribadi:** tidak dikumpulkan (tanpa nama, alamat email,
  nomor telepon, atau identitas lain).
- **Lokasi:** tidak dikumpulkan dan tidak diminta izinnya.
- **Data permainan:** seluruh progres permainan (koin, bangunan,
  hari, level, misi, pencapaian) hanya tersimpan di perangkat Anda
  sendiri dan tidak pernah dikirim ke server mana pun.
- **Pengaturan:** preferensi suara dan tutorial hanya tersimpan di
  perangkat Anda.
- **Iklan / pelacak:** game ini tidak menampilkan iklan dan tidak
  memakai SDK iklan, analitik, atau pelacak pihak ketiga.
- **Pembelian dalam aplikasi:** tidak ada.

## Izin perangkat

Game ini tidak meminta izin perangkat apa pun (tanpa akses kamera,
mikrofon, kontak, penyimpanan bersama, atau lokasi).

## Anak-anak

Game ini cocok untuk semua umur dan tidak mengumpulkan data dari
siapa pun, termasuk anak-anak.

## Perubahan kebijakan

Bila kebijakan ini berubah (misalnya karena fitur daring ditambahkan
di pembaruan berikutnya), versi baru akan diterbitkan di halaman ini
dan tanggal berlakunya diperbarui. Perubahan tidak berlaku surut
atas data Anda — karena memang tidak ada data yang kami simpan.
